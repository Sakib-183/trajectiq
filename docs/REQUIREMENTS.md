## Additional implemented features

Native WebGL interactive spacecraft hangar, pointer/keyboard camera controls, module selection/drop, phase-specific launch/transfer/orbit visualization, player-controlled science/energy/downlink schedules, 200-sample seeded robustness histogram, deterministic offline mission mentor with three explanation levels, JSON mission export, 3-question self-check, responsive layout, keyboard-native controls, modal focus trap, SVG fallback.

## Scope choices

- Pure browser ES modules instead of the recommended Next.js/TypeScript stack: same isolated engine boundaries, no installation/build requirement.
- Native WebGL renders a schematic 3D spacecraft, launch vehicle and orbit. Geometry changes with selected component classes; a 2D SVG fallback preserves gameplay on devices without WebGL. The scene is not an engineering CAD or flight dynamics system.
- No cloud AI. Rule-based explanations satisfy the required offline fallback. No facts or outcomes are generated by AI at runtime.
- No accounts, multiplayer, full n-body solver, second mission or leaderboard.
